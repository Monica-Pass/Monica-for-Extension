# 0.1.30 Nothing 详情布局与验证记录

日期：2026-09-11。本地开发包，保留工作区已有未提交改动。

## 本轮改动

统一登录项、银行卡、证件、账单地址、支付账号、安全笔记、验证码和 Passkey 的详情布局，并检查 Wi-Fi、SSH、条码及 SSO 登录类型。

- 使用 Nothing 的黑白配色、平面表面、细边框和三级信息层级。沿用本地打包的 Space Grotesk、Space Mono；品牌继续使用 Doto，没有新增远程字体或依赖。
- 名称和状态位于顶部，主要字段与自定义字段分组，来源和时间在宽屏显示为侧栏。短字段成对排列，长网址、凭证 ID 和密钥自动换行。
- 窄屏自动改为单列，长内容在对话框内滚动，“编辑／关闭”保留在底部；复制反馈在操作区内显示。
- 登录验证码位于密码之后。独立验证码详情也显示当前代码、复制操作和倒计时，HOTP 成功复制后保存计数器。
- 受保护字段按条目和字段索引独立控制显示状态，重复字段名互不影响。密码、PIN、安全码、自定义秘密字段及 SSH 私钥默认完整遮蔽；银行卡号等识别字段保留末四位。
- 补齐 SSH 私钥、密钥位数、Wi-Fi 隐藏网络、安全笔记自定义字段，以及 Passkey 的可发现／用户验证状态；笔记内容可直接复制。
- KeePass 历史、附件管理、MDBX2 诊断／快照／历史及安全发送详情同步调整标题、事实字段、段落和操作间距。
- 保留既有八语言、Android 数据模型、自动填充、Passkey 和旧后台恢复逻辑。验证码继续使用共享前台时钟和现有缓存。

## 验证结果

浏览器检查使用隔离 Chromium 配置及合成数据，没有访问用户实际密码库。

| 检查 | 结果 |
| --- | --- |

| 浏览器回归 | 一次运行 72 项全部通过，覆盖 21 个测试文件 |
| 新详情浏览器用例 | 6 项通过，包含 13 种条目场景的深浅主题、390px 手机、320×360px / 200% 字号、重复秘密字段、短秘密遮蔽、SSH／笔记复制、独立 HOTP 持久化及八语言底部操作 |

| 兼容性 | 登录 OTP、KeePass 历史恢复、三类密码源附件、安全发送、MDBX2 诊断与恢复、自动填充、Passkey 和更新恢复用例通过 |

Windows 系统剪贴板会将多行文本转换为 CRLF；复制回归仅对这一平台换行差异归一化后比较，保留字段内容的完整检查。

本轮未重跑全部 E2E、Native Host 硬件验收或整套跨平台互操作验收。构建仍有原有的大体积代码块提示。产物为使用 `--allow-dirty` 生成的本地开发包。
