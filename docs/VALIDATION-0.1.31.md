# 0.1.31 Nothing 模块化概览与验证记录

日期：2026-09-11。本地开发包，保留工作区已有未提交改动。

## 本轮改动

直接将现有概览页改为模块化密码库首页，沿用 Nothing 的黑白配色、平面表面、细边框及本地打包的 Space Grotesk、Space Mono 和 Doto 字体。

- 首页包含常用卡片、收藏夹、条目类型、分类与文件夹、数据库、归档与回收站六个模块。顶部可设置模块显示、隐藏和排序，支持实时预览、取消、保存及恢复默认布局；全部隐藏后仍保留恢复入口。
- 常用卡片采用堆叠布局，支持手动添加和移除，最多固定 24 项。默认推荐从收藏及最近更新中选取六项，并非真实使用频率统计。清空卡片会保留明确的空状态，不删除密码库条目；“使用推荐卡片”可恢复推荐。
- 收藏夹支持展开与收起。八种条目类型、文件夹、数据库、归档和回收站入口继续使用原有列表、分页、详情及编辑流程；概览搜索按 Enter 后进入跨类型结果列表。
- 默认汇总全部数据库，顶部可切换为单个数据库。卡片和文件夹显示来源；不同数据库中同名或同 ID 的文件夹分别处理。数据库模块持续提供全部来源入口，活跃条目计数排除归档和已删除项。
- 数据库范围在页面内导航时保留，重新加载或锁定后重置。模块顺序与可见性、固定条目 ID、收藏夹展开状态存入加密密码库，并随完整备份恢复。恢复默认布局保留固定卡片和收藏夹偏好。
- 桌面条目类型采用四列两行，自定义模块采用竖直排序列表。窄屏减少列数、允许操作换行，支持深浅主题、八种语言及 200% 字号。
- 首页仅使用安全摘要，不展示密码、OTP 种子、笔记正文、私钥或含令牌的登录网址。偏好读写仅允许已解锁的完整管理页调用，经既有持久化写入队列保存。
- 沿用 Vue、现有存储及分页机制，没有为首页引入 Rust 或修改 MDBX2 Native Host。首屏仅渲染一张正面卡片、六条收藏；文件夹和数据库每页六条、选卡器每页八条，原列表每页 50 条。
- 为英文及六个外部语言目录补充 51 条首页文案；全部八种语言目录均为 2,821 个键。

浏览器覆盖文件为 `accessibility`、`bitwarden-folders`、`detail-layout`、`item-detail`、`keepass-groups`、`localization`、`locked-autofill`、`login-otp-detail`、`manager`、`multilingual`、`passkey`、`performance`、`responsive-layout`、`runtime-upgrade`、`security-boundaries`、`vault-home`、`visual-polish` 和 `wallet`，均位于 `tests/e2e/`。

本轮未重跑全部 E2E、Native Host 硬件验收或整套跨平台互操作验收。构建仍有原有的大体积代码块提示。产物使用 `--allow-dirty` 从既有工作区生成，属于本地开发包，并非签名或公开发布版本。最终生产构建后仅调整测试和文档，未再修改生产代码。
