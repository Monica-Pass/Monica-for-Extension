# 0.1.26 多语言与验证记录

日期：2026-09-11。本地开发包，发布证据如实记录尚未提交的工作树状态。

## 语言与切换

- 支持与 Android 版一致的八种语言：简体中文、英文、日语、韩语、德语、西班牙语、俄语和越南语。
- 登录页、管理页侧栏和 Popup 底部均可切换语言。默认“跟随浏览器”，按浏览器语言偏好顺序匹配支持的语言，并兼容区域代码；没有匹配时使用英文。
- 手动选择会持久保存，在管理页、Popup 和网页提示间同步；原有中英文设置继续有效。再次选择“跟随浏览器”可恢复自动选择。
- 保留 Nothing 明暗外观，主题默认跟随系统。语言切换不改变主题选择。
- 管理页、编辑器、密码源与恢复对话框、生成器、保存提示和 Passkey 确认均使用当前语言。八种语言的扩展名称、说明和工具栏标题也已提供。

每套非中文词库覆盖 2758 条应用文案，加载时检查覆盖范围和变量占位符。英文内置，其余六套语言文件分别按需读取并缓存；所有语言资源均在扩展安装包内，运行时不访问在线翻译服务。较慢的旧请求不能覆盖新语言选择，加载失败时保留可用界面并允许重试。

用户录入的账号名称、用户名、密码、备注、文件及第三方返回内容保持原样。切换语言保留编辑中的字段、已打开保存提示的保存位置和处理方式，以及 Passkey 确认中已选的账号。

新增六种语言复用了 Android 已翻译文案，其余初稿由离线翻译辅助生成；导航、认证、免解锁授权和 Passkey 确认等关键文案已校订。尚未经过各语种母语使用者的完整审校。详细维护说明见 [本地化支持范围](LOCALIZATION.md)。

## 多尺寸适配

保留 0.1.25 的 320–2560px 布局、至少 44px 的操作按钮、窄屏导航焦点管理和短窗口编辑器。本轮修复长译文造成的隐式网格最小宽度问题：空状态、概览指标和卡片标题可以收缩与换行，指标标签预留图标空间，避免德语和俄语挤出窗口。

语言选择器支持换行并限制在可用宽度内。登录页补充明确宽度，避免原生下拉框截断简体中文、日语等语言名称；在 390×640 / 100% 和 320×480 / 200% 下逐一检查八种语言的选中名称宽度。编辑器的内置本地密码库名称随语言切换，用户自定义密码源名称保持原样。

## 兼容性

本轮调整本地化、语言状态和布局，沿用已有密码库、Android 记录、Passkey 和同步格式。Android KeePass、MDBX2 与 Native Host 的互通验证见 [0.1.24 记录](VALIDATION-0.1.24.md)；本轮未重复运行 Android 和 Native Host 测试。此前多尺寸验证见 [0.1.25 记录](VALIDATION-0.1.25.md)。

普通登录项的免解锁填写仍需用户逐项标记，并执行网站、字段和文档匹配检查。验证码、Passkey、查看和编辑密码库仍需要解锁。可导出的受支持私钥可用于 Passkey 签名；只有 Android 设备密钥别名的 Passkey 继续保留为元数据，真实 Windows Hello 硬件验收仍受当前环境不可用的限制。

自动化验证覆盖了明确列出的界面和场景，不代表所有网站、屏幕阅读器或每种语言的完整人工验收。

## 安装与升级

新版 ZIP：`release/monica-extension-0.1.26.zip`。可加载目录：`release/monica-extension-unpacked`；开发构建位于 `dist`。

ZIP SHA-256：`a5291d7556fe49126c0f099a9f8dc8ad29604d7f265966438c40b4495e95e094`。

已安装的扩展请继续使用原加载目录，将新版文件更新到该目录后，在 Chrome/Edge 扩展管理页点击“重新加载”。首次安装可开启开发者模式并选择“加载已解压的扩展程序”。更换绝对目录可能改变开发者模式扩展 ID，原有本地数据不会自动迁移。

Windows 连接组件继续使用 `release/monica-mdbx2-host-windows-x64-0.1.0.zip`，安装说明见 [0.1.24 记录](VALIDATION-0.1.24.md#安装和升级)。

本地验证命令：

```powershell
node scripts/package-release.mjs --allow-dirty
node scripts/verify-release.mjs --allow-dirty
```

`--allow-dirty` 仅用于本地开发包；正常可信发布仍要求干净的工作树。本次没有提交或发布代码，没有修改日常浏览器配置或 Android 项目。

八语言总览与实际页面预览位于 `.artifacts/language-preview/`，Nothing 和多尺寸预览位于 `.artifacts/nothing-preview/`，均由最终打包扩展和合成账号生成。
