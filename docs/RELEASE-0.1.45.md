# 0.1.45 弹窗账号列表

> 本地开发阶段记录：文中的版本号未作为 GitHub Release 发布，相关改动已汇总到[正式版 0.1.37](RELEASE-0.1.37.md)。

浏览器工具栏弹窗改为紧凑的 M3E 分组列表：左侧网站图标，中间标题与用户名，右侧独立复制操作。同一账号的内容横向对齐，移除原先卡片里嵌套的大胶囊按钮。

- 匹配账号、全部登录项和免解锁账号共用行组件；Passkey 状态和证件/支付项目也采用 M3E 列表组件。
- 不可填充的浏览器页面显示正常可读的账号信息，保留复制操作；账号行不会成为可触发的填充按钮。
- 复制用户名、复制密码与填充是独立的点击/键盘操作，避免误填充。免解锁列表仍只提供已授权账号的填写操作。
- 长标题最多显示两行，用户名过长时省略并可悬停查看；网站图标不再被长文字挤偏，收藏星标和验证码标识保持独立。
- 工具栏弹窗从首次打开即使用 600px 高度，内容按需滚动；独立窗口继续适配可用高度。复制按钮保持 44px 点击区域，沿用组件的焦点、按压与减弱动画支持。
- 继续支持 Monica 与 Nothing 的深浅配色。没有新增依赖、字体或图标服务。

本轮不改变密码库持久化格式、Android 数据兼容、WebDAV / Bitwarden 同步或 Passkey 签名策略。

本地包与验证范围见 [0.1.45 验证记录](VALIDATION-0.1.45.md)。
