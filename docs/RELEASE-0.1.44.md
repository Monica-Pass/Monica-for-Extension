# 0.1.44 登录项网站图标

> 本地开发阶段记录：文中的版本号未作为 GitHub Release 发布，相关改动已汇总到[正式版 0.1.37](RELEASE-0.1.37.md)。

登录列表、全部项目、归档/回收站中的登录项、详情页及 Popup 现在会根据保存的网址显示网站图标，收藏星标独立保留。

- 优先读取 Chrome/Edge 的本地图标缓存；未命中时尝试网站自己的 `/favicon.ico`，不使用第三方图标服务。
- 支持带协议的网址、裸域名、多个网址及国际化域名；跳过应用链接、验证码链接和正则匹配规则。Wi-Fi、SSH 与条码保留类型图标。
- 图片加载失败、格式错误、超时或网站没有图标时，自动显示默认图标。编辑网址后会更新图标。
- 列表按可见范围加载，合并重复请求，限制并发和缓存大小，避免加载图标拖慢操作。

图标请求不携带登录网址中的用户信息、路径、查询参数、片段、Cookie 或 Referer，也不跟随重定向。直接请求限于默认端口的公开 HTTPS 来源；HTTP、IP 地址、内网名称等仅使用浏览器缓存。目标网站仍能看到图标请求及客户端 IP。没有缓存、未提供 `/favicon.ico` 或拒绝匿名请求的网站可能显示默认图标。

新增 `favicon` 权限用于浏览器图标缓存；未扩大网页可访问资源。网站图标只在页面内存中缓存，不改变 Android 数据格式、加密、WebDAV / Bitwarden 同步协议或 Passkey 策略。Monica 应用标识继续使用官方图标。

验证范围和本地安装包见 [0.1.44 验证记录](VALIDATION-0.1.44.md)。
