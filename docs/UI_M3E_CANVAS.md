# 用 m3e-canvas 规划 Monica 插件 UI

Monica 正式版 0.1.37 以 Material 3 Expressive 统一组件、形状、字体、动效和布局，Nothing 只作为可选配色。详情与编辑的信息顺序参考 Monica Android。m3e-canvas 用于可编辑的布局稿；实际界面由 Vue 3 和 `@m3e/web` 2.6.1 实现。下文 0.1.42–0.1.44 指本地开发阶段编号，相关改动统一纳入正式版 0.1.37。

`@m3e/web` 是 [M3E 项目](https://github.com/matraic/m3e)发布的 Web Components 库，不是 Google 官方维护的 Material Web。插件使用该库真实的组件、状态层、键盘行为和表单关联，不再以原生输入框外的 CSS 描边模拟 Material 控件。

## 参考项目

- 项目：[lnkiai/m3e-canvas](https://github.com/lnkiai/m3e-canvas)。本轮检查的提交为 [27a9d12409c2d468d34d70e62f317a4909436f34](https://github.com/lnkiai/m3e-canvas/tree/27a9d12409c2d468d34d70e62f317a4909436f34)，日期 2026-09-14。
- Canvas 本身是 Next.js / React 原型编辑器，支持 JSON 项目、交互预览、设计提示词和分享链接；它推荐的实际 Web 实现是 M3E Lit 组件。Monica 已使用对应的 `@m3e/web`，无需迁移框架。
- 已核实上游 `LICENSE` 为 MIT。上游 `NOTICE` 另外说明加载动画含 Apache-2.0 来源代码与 Material 图形资源。本轮没有复制这些动画、SVG、React 组件或编辑器代码到插件，运行时依赖及许可证清单保持原有组成。

## 可编辑布局稿

在 [m3e-canvas](https://lnkiai.github.io/m3e-canvas/) 选择打开项目，导入 [monica-vault.m3e.json](design/monica-vault.m3e.json)。包含六个页面、62 个组件组：密码库、新建类型、项目详情、编辑项目、窄屏密码库、拆分新建菜单。主要新建、详情、编辑和返回路径已连接。

文件使用虚构的 `example.test` 数据，描述布局和主要操作，不包含真实密码、令牌、数据库或浏览器配置。已经通过上游在线编辑器的实际导入与渲染检查。草图的通用字体和控件细节供排版使用，最终外观与完整功能以插件为准。

当前会话未提供 m3e-canvas 专用 skill 或 MCP，因此使用其公开源码、文档和可导入的 JSON 项目。Canvas 的 `splitButton` 只支持整个节点的跳转；稿件以独立菜单页和组件注释表达两侧行为，实际插件具有两个独立操作。

## 已实现的调整

| 页面 | 变化 | 用户收益 |
| --- | --- | --- |
| 密码库、钱包、笔记、验证码、API 密钥、归档与回收站 | 连续列表替代多列散卡；名称、摘要、来源和操作对齐 | 长标题更容易阅读，来源和操作位置更稳定 |
| 密码库筛选 | 数据库切换和收藏入口直接显示；其他条件显示摘要与清除入口 | 不必每次打开筛选弹窗，也能知道当前列表范围 |
| 顶部新建 | 使用原生 M3E 拆分按钮；左侧直接打开当前页面或筛选类型的创建弹窗，全部项目默认新建登录项。右侧展开全部类型并标记当前类型 | 无需二次选择，也能从右侧跨类型创建 |
| 新建项目 | 账号与安全、钱包与其他各为一组连续列表，窄窗口改成上下分组 | 宽屏可直接看到全部 11 种手动创建类型 |
| 项目详情 | 名称、主要凭据、绑定验证码和网址优先；附加参数、自定义字段折叠；来源记录放到宽屏侧栏 | 常用内容无需展开，复杂字段仍完整保留；标题与底部操作固定 |
| 登录、API 密钥和其他类型编辑器 | 名称置前，来源紧凑显示；编辑时移除重复的只读类型；核心字段和补充信息分组 | 填写顺序与键盘顺序一致，正文滚动时保存操作仍可用 |
| 菜单、选择器与展开区域 | 统一色阶表面、圆角、选中态和焦点；菜单按窗口高度滚动 | 大字体、长翻译和短窗口都能访问完整内容 |
| 创建、解锁与工具栏主密码框 | 对照 Canvas 的 `textField`：默认 56px 高、16px 圆角、outlined 变体；实际标签、焦点及校验由 M3E form-field 管理。设备密钥说明使用辅助文字 | 浮动标签清楚，窄屏大字号下不与说明挤在一起 |
| 项目列表交互 | 整行承担悬停状态，M3E focus-ring 覆盖整个项目；标题内部不再叠加局部状态层 | 鼠标与键盘反馈范围一致，编辑／删除仍为独立操作 |

2026-09-15 再次核对 Canvas 上游，HEAD 仍为上述提交。输入框规格来自 `lib/tokens.ts` 的 `textField` 定义，组件、形状、排版及动效均以 M3E 为准；Nothing 设计规则不参与这些决定。

默认使用 Monica 青绿色；已有 Nothing 配色偏好保持不变。`nothing.css` 仅定义颜色变量，不覆盖字体、布局、形状或动效。所有配色共用 M3E 分段选择、圆角分组、状态层与短动效，并尊重“减少动态效果”。Monica 官方彩色应用图标保持原样。

界面使用系统字体栈 Roboto / Segoe UI / Microsoft YaHei UI，凭据使用系统等宽字体；不请求远程字体。移除 Doto、Space Grotesk 和 Space Mono 字体资源。Material Symbols 本地子集保留填充状态轴；构建验证图标覆盖和文件哈希。

拆分菜单支持 ArrowUp / ArrowDown、Home / End、Escape、外部关闭和焦点恢复，页面切换时自动关闭。无 Popover API 的浏览器回退到完整类型选择器。表单使用 `m3e-select` / `m3e-option` 的真实菜单；无 Popover API 时，在相同的 M3E 表单容器中回退为原生选择器。Passkey 仍由网站的 WebAuthn 流程创建，不添加无效的手动创建入口。

## 0.1.43 组件迁移

| 用途 | 实现 |
| --- | --- |
| 文本、密码、数字与多行输入 | `m3e-form-field variant="filled"`；按库文档组合原生 `input` / `textarea`，由组件绘制标签、底部指示线和状态 |
| 表单下拉 | `m3e-select` / `m3e-option`，受控选中项保留原值、空选项和禁用项 |
| 多选、单选与设置开关 | `m3e-checkbox`、`m3e-radio-group` / `m3e-radio`、`m3e-switch`；异步设置写入失败时保留实际已保存状态 |
| 搜索、生成器与页签 | `m3e-search-bar`、`m3e-slider` / `m3e-slider-thumb`、`m3e-tabs` |
| 新建、编辑和外观 | `m3e-dialog`、`m3e-segmented-button`，保留模态、焦点返回和表单提交行为 |
| 折叠信息与设置分组 | `m3e-expansion-panel`，展开指示和动效交给组件 |
| 多行操作入口 | `m3e-list-action` 的 leading、supporting-text、trailing 插槽，用于密码源、项目、文件夹和历史记录 |
| 组织与安全发送选择 | `m3e-selection-list` / `m3e-list-option`，由组件管理键盘选择和选中语义 |

清理旧输入框外框、按钮上的网格布局、重复焦点圈和展开动画，避免在组件表面外再叠一层形状。保留必要的状态提示、焦点环、错误信息和强制颜色模式支持。

针对 2.6.1 的少量适配集中在 `material-controls.ts`、`material-dialog.ts`、`action-button-layout.ts` 和 `menu-layout.ts`：关联可访问标签，更新 Vue 改写的选项文字，隔离下拉菜单的 Escape，修正 Shadow DOM 插槽的 Tab 边界，并限制大字体下的按钮触摸区域及弹窗留白。适配保留库自身的状态、菜单和模态实现。长标题与长翻译允许换行；窗口变矮时保留可见的保存操作。

复杂来源管理、附件和详情流程仍使用既有弹窗容器，本次迁移其中的表单、展开项和列表操作；没有改动数据操作的确认边界。

弹窗关闭事件限定为组件自身，收起内部展开区域不会取消编辑。两步验证区域的展开状态与绑定内容分开保存，取消绑定后可继续填写内嵌密钥。紧凑登录列表使用单行标题和摘要省略，完整内容可通过详情或标题提示查看，项目名称保留在可访问标签中；其余多行入口按可用宽度换行。

## 数据与实现范围

新增的数据库选择器与收藏入口复用已有筛选状态；改变的是浏览范围，不改变项目所属数据库。筛选结果为空时提示调整条件，避免误报整个密码库为空。

本轮未改变密码库序列化格式、Android 类型映射、API 密钥格式、WebDAV / Bitwarden 同步协议或 Passkey 计数策略。后台同步、编辑版本检查、加密保存与敏感字段显示继续使用现有服务。

主要实现位于 `src/material.css`、`src/material-manager.css`、`src/detail-layout.css`、`src/components/CreateSplitButton.vue`、`src/manager/create-items.ts` 和三个编辑器组件。共享主题与管理页覆盖分开加载，避免 Vite 共享 CSS 的顺序破坏详情和编辑器布局。

本轮验证范围与本地安装包见 [0.1.43 验证记录](VALIDATION-0.1.43.md)。0.1.42 的布局调整记录保留在[上一版验证记录](VALIDATION-0.1.42.md)。

## 0.1.44 网站图标

登录项在原有 M3E 前导图标位置显示网站 favicon，图片固定为 24 × 24，不改变列表行高；收藏状态使用独立小星标。加载中、无网站或失败时显示本地 Material Symbols，Wi-Fi、SSH 与条码保留类型图标。详情、列表及 Popup 共用同一组件，Monica 官方应用图标与配色不变。

图标按可见范围加载，复用浏览器缓存和有容量上限的内存缓存；加载失败不增加弹窗或打断填充操作。验证与交付见 [0.1.44 验证记录](VALIDATION-0.1.44.md)。
