# 0.1.27 性能优化与验证记录

日期：2026-09-11。本地开发包，保留当前尚未提交的工作树状态。

## 交付内容

保留 Nothing 黑白界面、默认跟随系统主题、八种语言、多尺寸布局、Passkey、自动填充和逐项授权的免解锁填写。本轮集中减少大列表、验证码、网页监听器、字体和词库的开销。

- 管理页每页最多渲染 50 条，Popup 每区最多 20 条；全库搜索不受页数限制，筛选重置页码，删除末页内容后自动调整。
- 验证码共享可见页面计时器并缓存当前周期。HOTP 无周期计时器，隐藏页面暂停，复制时再次确认当前值。
- 锁定后清理界面快照、派生缓存和编辑状态，避免先前异步刷新重新显示旧数据。
- 动态网页移除组件时释放对应 ShadowRoot、observer 和监听器。
- 图标字体由 3,961,284 字节精简为 21,164 字节，保留 221 个实际使用图标和 Nothing 外观参数。
- 英文之外最多保留两套词库，普通网页延迟初始化提示语言；生成器、Secure Send 和二维码生成依赖按需加载。
- 修复真实工具栏首次打开时可能缩为 35px 的循环宽度计算，现明确请求 390px；独立 Popup 保留窄屏和短窗口适配。

完整测量方法、结果与维护命令见 [性能说明](PERFORMANCE.md)。同一 Chromium 下，2,000 个账号的登录页保留 V8 堆从 59.74 MiB 降至 8.08 MiB，Popup 从 14.07 MiB 降至 5.79 MiB。数据只代表测量页面的 JavaScript 堆，不是浏览器总内存；64 MiB Argon2id 参数没有降低。

## 数据和兼容性

密码库加密信封、主密码派生、Android 记录和同步协议未改动。浅层快照和分页只改变界面数据保留及渲染方式；搜索仍使用全部项目。免解锁权限继续逐项授权，仅允许已标记的普通登录项按网站规则填写用户名与密码，验证码、Passkey、详情与修改仍需解锁。

Android KeePass、MDBX2 和 Native Host 的互通验证沿用 [0.1.24 记录](VALIDATION-0.1.24.md)，本轮没有重复运行这些未受修改影响的套件。只有 Android 设备密钥别名的 Passkey 仍为元数据；支持的可导出私钥才能在浏览器签名。真实 Windows Hello 硬件验收仍未在当前环境完成。

语言词库现各覆盖 2,763 条应用文案。新语言尚未完成母语使用者的完整人工审校，自动化测试也不代表对所有网站、屏幕阅读器和显示环境的保证。详见 [本地化支持范围](LOCALIZATION.md)。

## 安装和升级

- ZIP：`release/monica-extension-0.1.27.zip`，1,860,460 字节，约 1.77 MiB。
- 可加载目录：`release/monica-extension-unpacked`；开发构建：`dist`。
- ZIP SHA-256：`f2b83faf70c4fbf0132577ef7eb8e4132eb47866c0f25bd4e40e43723ec6d933`。
- Windows 连接组件继续使用 `release/monica-mdbx2-host-windows-x64-0.1.0.zip`。

已有安装请沿用原来加载的绝对目录，完整更新文件后在 Chrome/Edge 扩展管理页点击“重新加载”，以保持原扩展 ID 与本地数据。首次安装可开启开发者模式并加载上述解压目录。

本次安装包由以下命令生成与验证：

```powershell
node scripts/package-release.mjs --allow-dirty
node scripts/verify-release.mjs --allow-dirty
```

`--allow-dirty` 标记本地开发包，正常可信发布仍要求干净工作树。本次没有提交或发布代码，也没有修改日常浏览器配置或 Android 项目。

预览来自最终打包扩展的合成数据：`.artifacts/nothing-preview/` 为外观和多尺寸截图，`.artifacts/language-preview/` 为八语言截图，`.artifacts/performance/pagination-desktop.png` 和 `pagination-narrow.png` 为分页效果。性能原始结果保存在 `.artifacts/performance/before.json` 与 `after.json`。
