# Monica for Extension 0.1.36

本版本汇总模块化密码库概览、网页表单旁自动填充、详情布局、多语言和官方品牌图标的更新。

## 更新内容

- 聚焦账号、密码或验证码输入框，在旁边选择匹配的登录项。支持鼠标、方向键、Enter 和 Esc，菜单跟随表单位置；可在“设置与备份 → 表单旁自动填充”关闭并立即生效。
- 概览支持常用卡叠、收藏夹、类型、文件夹、数据库、归档与回收站；可调整模块顺序和显示状态，并选择当前数据库范围。
- 登录项直接显示关联验证码，改善详情页、长内容和窄屏布局；修复 Android WebDAV 验证器关联的绑定、更换和解除。
- 提供八种离线语言、浅／深色及 Nothing 风格。管理页、工具栏和网页提示全部使用 Monica 官方彩色图标。
- 改善大列表分页、验证码刷新与旧运行时更新提示，保留已授权的免解锁填写功能。

## 安装与更新

下载 `monica-extension-0.1.36.zip` 并解压，目录根部应有 `manifest.json`。在 Chrome／Edge 的扩展管理页开启开发者模式，选择“加载已解压的扩展程序”。

已有用户应更新到原先加载扩展的目录，再点击“重新加载”、重新打开管理页并刷新登录网页，以保留原扩展 ID 和浏览器本地存储。

## 发布文件

Release 提供安装 ZIP、SHA-256 校验文件、依赖 SBOM、许可证清单和构建来源记录。安装包只包含扩展程序与发布元数据；已有账号、主密码、验证码密钥、浏览器配置及导出的密码库不属于发布文件。

截图和自动化验证均使用虚构账号与隔离浏览器。数据库及密码源的实际兼容范围见 [Android 互通记录](VALIDATION-0.1.33.md)，新增菜单与品牌修正见 [自动填充验证](VALIDATION-0.1.35.md) 和 [图标验证](VALIDATION-0.1.36.md)。
