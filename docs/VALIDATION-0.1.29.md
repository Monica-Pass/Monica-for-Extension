# 0.1.29 登录项验证码显示与验证记录

日期：2026-09-11。本地开发包，保留已有未提交改动。

## 问题与修复

登录项详情原先把“动态验证码”写成固定文本“已绑定验证器”，复制按钮也复制这段文本。独立验证器绑定没有参与详情展示。新增浏览器用例在 0.1.28 构建上复现：详情存在，但找不到真实验证码的复制按钮。

0.1.29 在该位置显示当前验证码、剩余秒数和复制按钮，沿用现有验证码组件与绑定解析规则：

- 支持内嵌 Base32、otpauth URI，以及绑定的独立验证器；保留算法、位数、周期等参数。
- 独立验证器优先，包含已归档的验证器。Android 的反向绑定继续按密码源匹配；已删除的验证器不参与绑定解析。
- 点击复制时重新检查当前周期，避免复制刚过期的验证码。密钥或绑定不可用时显示“不可用”，禁用复制。
- HOTP 仅在剪贴板写入成功后更新实际来源项目的计数器。保存与刷新完成前禁用重复复制，内嵌 HOTP 的更新仍保存在登录项中。
- 继续使用每个可见文档共享的计时器和每个展示组件的短期缓存；隐藏页面清除 TOTP 展示，回到页面后刷新，锁定时移除详情。
- 新说明和错误反馈支持八种语言。倒计时改用主题文字颜色，修复深色模式下 3.03:1 的文字对比度问题。

检查之前的测试改动时，发现兼容性用例替换了原有客户端测试文件。本轮把原来的 17 个运行时命令用例恢复到 `src/runtime/client-commands.test.ts`，保留现有的 8 个兼容性用例。
