# Password project detail

Separate credential groups from password rows. Group labels and shared usernames identify each group; numbered password rows select the original record and its own content/history. No secret appears in navigation. The selected row is marked visually and with aria-current; keyboard activation remains available. Unknown or inconsistent metadata falls back to explicit numbered rows without inventing account groups. A known singleton keeps its group identity.

Reuse Monica teal surface/selection tokens, Segoe UI/Microsoft YaHei UI, 16px body text, 12px portrait gutters, 24px outer/4px joined corners, 48px minimum touch actions. The design keeps current row details and protected reveal/copy actions below navigation.
