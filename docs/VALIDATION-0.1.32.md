# 0.1.32 首页易用性优化与验证记录

日期：2026-09-13。本地开发包，保留工作区已有未提交改动。

## 本轮改动

在 0.1.31 的模块化概览上，完善日常选卡、切换数据库、复制和处理同步状态的流程。继续使用 Nothing 的黑白配色、平面表面、细边框，以及本地打包的 Space Grotesk、Space Mono 和 Doto 字体。

- **批量管理常用卡片**：候选项支持多选，已选项支持拖动或键盘上下按钮排序。保存后统一生效，取消会丢弃草稿。最多固定 24 项，候选项每页八条；安全摘要帮助区分同名账号。已选列表包含全部数据库，候选列表遵循当前范围。已归档、已删除或缺失的固定项可以明确清理，操作只移除首页卡片，不删除密码库条目。
- **记住数据库范围**：首次使用显示全部数据库，之后默认记住从顶部下拉框选择的范围。可设置每次打开全部数据库、指定数据库或上次选择的数据库；设置在下次解锁或重新打开管理页生效。页面内临时导航继续保留当前上下文；来源缺失时回到全部范围并提示，保存失败可以重试。
- **紧凑与舒适布局**：默认紧凑，减少标题、卡片及模块间距；自定义面板支持实时预览、保存与取消。恢复默认布局重置模块及密度，保留数据库、固定卡片和收藏夹偏好。全部模块隐藏后仍能恢复设置。
- **首页快捷复制**：登录卡片显示验证码关联标记，可以复制用户名或验证码；独立验证码卡片也支持复制。关联不可用时禁用验证码复制并说明原因。每次操作从已解锁管理页权限边界读取当前条目；验证码按点击生成，HOTP 在复制成功后才推进计数器。锁定或离开页面会取消尚未派发的复制请求，结果以内联文字反馈。
- **数据库状态入口**：根据既有元数据、待写队列及冲突记录，显示本地、停用、待同步、已同步、需确认、冲突或错误等已知状态，并显示有效的上次同步时间。“查看并处理”打开原有密码源页面，滚动到对应数据库并将键盘焦点放到标题。不会展示原始错误载荷，也不会把这些摘要当成实时联网检测。
- **独立设置合并保存**：首页偏好按修改字段合并，经既有串行持久化队列存入加密密码库，避免多个管理页覆盖彼此修改的不同字段；同一字段仍以最后保存为准。旧库默认值、完整备份恢复以及管理页专属权限保持兼容。
- **大库选卡搜索**：缓存安全摘要、类型及来源的搜索文本，避免每次输入重新处理全库。首页继续有界渲染，完整列表仍使用既有分页。没有修改数据库格式、加密参数、Rust 或 Native Host，也没有引入新依赖。
- 为英文及六个外部语言目录补充 33 条文案，全部八种语言均为 2,854 个键。新增设置具有明确的读屏标签；首页不会显示密码、验证码密钥、生成的验证码或笔记正文。

## 性能测量

同一台机器顺序运行 0.1.31 和 0.1.32。5 万条合成登录项场景下，连续五次选卡搜索的中位耗时从 111.5 ms 降到 15.5 ms，最大样本耗时从 132.1 ms 降到 41.8 ms；首个查询包含搜索索引建立时间。

该结果不表示整体启动提速。5 万条时，已解锁页面的一次冷重载采样分别为 6.68 秒和 8.01 秒；返回首页后的保留 V8 堆分别为 34.31 MiB 和 40.77 MiB。本轮新增交互和缓存有空间开销，全库读取及搜索仍随数据量增长。数据库切换测量不包括随后异步保存偏好的时间；保留 V8 堆也不等于浏览器总内存。

完整指标、测量条件、原始记录及复现命令见 [性能测量与维护](PERFORMANCE.md#0132-首页搜索测量2026-09-13)。这些是本地小样本观测，不是延迟或内存上限保证。
