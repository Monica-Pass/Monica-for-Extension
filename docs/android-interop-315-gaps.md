# Android 1.0.315 interoperability: field/backend gap register

Baseline 2026-09-30; extension 0.1.37, HEAD `11f712e5599eb439a6d108b918b620918f50d117`, dirty working tree preserved. Android source appendix is a model declaration snapshot, not a wire schema. This register begins with source findings; no row below is an application E2E pass.

Capability columns distinguish reading (R), lossless preservation (P), editing/creation (E), and business operations (O). `pending` means not yet tested. ZIP, MDBX, KDBX and Bitwarden are separate adapters.
