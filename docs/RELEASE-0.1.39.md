# 0.1.39 按来源处理 Passkey 计数

> 本地开发阶段记录：文中的版本号未作为 GitHub Release 发布，相关改动已汇总到[正式版 0.1.37](RELEASE-0.1.37.md)。

修正 0.1.38 对 Bitwarden 历史非零凭据统一归零的行为，避免破坏已有网站的计数预期。

- Bitwarden 新凭据和零计数凭据保持 0，登录不因此上传 Cipher。历史非零计数先同步、递增并确认服务器写入后再签名；保留父登录、其他 Passkey 和未处理的同步队列。
- 全量快照手动导入成为独立的本地 Passkey，保留凭据与备份标志，清除旧同步绑定。插件自身含密码源设置的加密整库恢复维持原设计。
- 本地／MDBX2／KDBX 使用零签名计数，使用次数和时间只在本机更新，不再为一次登录改写数据库或新增历史。
- 取消、锁定、版本冲突或无法确认远端写入时不返回签名；后台重启后不把未完成的签名回执当作已完成。

非零计数固定不变同样可能被网站拒绝。旧独立副本若需迁移为零计数，应在网站重新注册。Android 当前历史非零 Bitwarden 路径仍与官方有差异，本版没有修改 Android 应用。

详见 [兼容策略](PASSKEY_COMPATIBILITY.md) 和 [验证记录](VALIDATION-0.1.39.md)。更新时替换原扩展加载目录并重新加载，再刷新登录网页。
