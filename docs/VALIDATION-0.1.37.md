# 0.1.37 正式发布验证

GitHub 上一正式版为 0.1.36；本次正式版本统一为 0.1.37，包含此前标为 0.1.37–0.1.45 的本地开发成果。原导航与 API 密钥阶段的记录保存在 [开发验证存档](development/VALIDATION-navigation-20260914.md)。

## 发布门禁

正式发布按用户要求暂缓，当前只更新本地源码和加载目录。发布前仍需完成干净 Git 提交上的 `npm run release:windows`，覆盖供应链、生产依赖审计、Rust 测试与 Clippy、全量单元测试、构建、安全审计、Bitwarden 互操作、浏览器 E2E 及独立可复现打包。

初次门禁已通过供应链检查、生产依赖审计（0 个漏洞）、50 项 Rust 测试、隔离 Windows Hello Host 探针和 Clippy。全量 Vitest 的 1,306 项中，1,305 项通过，权限说明遗漏 `favicon` 导致 1 项失败；已补充该权限及网站图标网络请求说明，对应发布文档检查复测通过。尚未完成正式版本的全量浏览器与最终发布门禁，不能把上述结果视为完整发布验收。

## 2026-09-15 密码框与整行交互

- 创建、解锁与 Popup 的主密码输入使用 `@m3e/web` 的圆角 outlined form-field 和浮动标签。Popup 将设备密钥说明放到辅助文字中，避免长标签在大字号下截断。解锁卡片修复内容宽度被重复扣除内边距的问题，并去掉装饰性描边。
- 普通项目、登录项、归档与回收站统一使用整行悬停反馈，取消标题区域重复的状态层。键盘焦点由 M3E focus-ring 覆盖整行，编辑、删除等按钮仍保留独立焦点与点击行为；颜色过渡遵循减少动效偏好。
- 无障碍、M3E 交互与视觉检查共 29 个浏览器场景通过。首轮 26 项通过，另外 3 项因 Windows 长路径导致临时 IndexedDB 打开失败，改用短临时输出路径后全部通过。
- 隔离浏览器额外复核浅色、深色、Nothing 深色三种外观，分别检查桌面与 320px / 200% 字号：输入框居中、无水平溢出、整行焦点尺寸、Enter 打开详情及编辑／删除隔离均通过。登录项、归档与回收站的整行键盘焦点也已检查。所有截图仅含虚构记录。
- 最终 Popup 无障碍检查再次通过；真实工具栏探针验证 390×600、200% 字号、六种额外离线语言，以及全局搜索与复制回退。
- TypeScript、字体图标校验、生产构建与产物安全审计通过。保持 0.1.37，GitHub 推送与 Release 继续暂停。

## 2026-09-15 拆分新建按钮

- 两侧按钮保持相同的实际高度，随字号或主按钮文字换行一起伸展；悬停和键盘聚焦时同步内侧圆角。使用 M3E 公开样式变量和布局规则，没有增加尺寸轮询或逐帧脚本。
- 左侧直接打开当前页面或类型筛选对应的创建弹窗；全部项目未限定类型时默认新建登录项，不再弹出二次选择器。右侧菜单保留原有展开效果、11 种类型及键盘导航；不支持 Popover 的浏览器仍从右侧进入完整选择器。
- 18 个相关浏览器场景通过，覆盖各页面直接创建、类型筛选、跨类型菜单、API 密钥保存、焦点返回、无障碍、窄屏和大字号。额外在桌面及 320px / 200% 字号下测量两侧高度与圆角并检查截图。
- TypeScript、生产构建、字体图标校验与产物安全审计通过；本地版本保持 0.1.37，发布继续暂停。

## 验证范围

自动化检查使用合成数据和隔离的临时目录，不连接用户的真实密码库。此前已完成的分阶段验证保留在开发文档中，不等同于本次正式提交的完整门禁结果。Android 真机、实际云账号及真实网站的多端并发验收不包含在这些自动化测试中。
