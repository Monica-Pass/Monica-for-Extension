# 0.1.37 正式发布验证

GitHub 上一正式版为 0.1.36；本次正式版本统一为 0.1.37，包含此前标为 0.1.37–0.1.45 的本地开发成果。原导航与 API 密钥阶段的记录保存在 [开发验证存档](development/VALIDATION-navigation-20260914.md)。

## 发布门禁

正式发布按用户要求暂缓，当前只更新本地源码和加载目录。发布前仍需完成干净 Git 提交上的 `npm run release:windows`，覆盖供应链、生产依赖审计、Rust 测试与 Clippy、全量单元测试、构建、安全审计、Bitwarden 互操作、浏览器 E2E 及独立可复现打包。

初次门禁已通过供应链检查、生产依赖审计（0 个漏洞）、50 项 Rust 测试、隔离 Windows Hello Host 探针和 Clippy。全量 Vitest 的 1,306 项中，1,305 项通过，权限说明遗漏 `favicon` 导致 1 项失败；已补充该权限及网站图标网络请求说明，对应发布文档检查复测通过。尚未完成正式版本的全量浏览器与最终发布门禁，不能把上述结果视为完整发布验收。

## 2026-09-15 语言入口调整

- 语言切换仅保留在“设置与备份 → 界面语言”。创建页、解锁页与 Popup 移除重复入口，继续使用已保存的语言或浏览器语言。
- i18n 与发布文档检查共 44 项通过；TypeScript、225 个字体图标校验、生产构建及产物安全审计通过。
- 浏览器相关场景共 17 项通过：首轮通过中英文切换、主题、大字号、锁定自动填充、登录填充及设置页语言名称等 11 项；另外 6 种语言在从 Popup 解锁后重新打开管理页，再使用设置入口完成复测。验证八种语言的离线使用、跨页面更新、用户数据保留与窄屏操作。
- 真实工具栏 Popup 验证 390×600、200% 字号、六种额外离线语言、全局搜索与复制回退。八张商店截图重新由隔离浏览器中的虚构记录生成，12 项官方图标显示检查通过。
- 本地包的源提交与 SHA-256 以包内构建证据及并列校验文件为准。更新包不代表已经推送 GitHub 或发布 Release。

## 数据边界

提交与产品包分别检查；真实数据库、备份、浏览器配置、`.artifacts`、构建缓存与本地测试报告不属于源代码或 Release 附件。商店截图只使用隔离浏览器与合成记录。网站图标 HTTPS 测试证书仅作为公开测试夹具留在源码中，不进入产品包。

初次候选提交的 Git index 导出后，Gitleaks 8.30.1 扫描得到 35 处匹配；逐项核对均为公开 OTP 测试向量、合成测试密钥／字段、对象 UUID 或源代码标识，没有发现用户凭据。没有把整个测试目录加入忽略规则。最终安装包仍需独立检查文件清单与内容。

## 验证范围

自动化检查使用合成数据和隔离的临时目录，不连接用户的真实密码库。此前已完成的分阶段验证保留在开发文档中，不等同于本次正式提交的完整门禁结果。Android 真机、实际云账号及真实网站的多端并发验收不包含在这些自动化测试中。
