# 0.1.42 Material 3 Expressive

> 本地开发阶段记录：文中的版本号未作为 GitHub Release 发布，相关改动已汇总到[正式版 0.1.37](RELEASE-0.1.37.md)。

Monica 插件的布局、控件、字体与动效统一采用 M3 Expressive。Nothing 保留为黑白红配色，已有配色偏好会继续保留；新安装默认 Monica 青绿色。

- 每个页面顶部使用拆分新建按钮：左侧创建当前类型，右侧选择其他类型。菜单支持键盘、当前类型标记、窗口内滚动与焦点恢复。
- 详情参考 Monica Android，优先显示名称、凭据、关联验证码和网址，更多参数与自定义字段折叠展示。
- 新建与编辑按信息顺序分组，移除编辑时重复的只读类型。正文滚动时保留标题和保存操作。
- 菜单、表单下拉、设置展开区域、外观选择器和 Popup 使用统一色阶与圆角，支持明暗主题、大字体和减少动态效果。
- 改用系统字体并移除旧字体文件；保留 Monica 官方应用图标和本地 Material 图标，无远程字体请求。

继续使用现有 Vue / M3E 组件，没有增加运行时依赖。Android 数据格式、WebDAV / Bitwarden 同步与 Passkey 策略沿用现有实现。旧浏览器的菜单和表单下拉保留兼容回退。

附带六页 [m3e-canvas 布局稿](design/monica-vault.m3e.json)，全部示例为虚构数据。参考方式见 [设计说明](UI_M3E_CANVAS.md)，检查结果与本地包见 [验证记录](VALIDATION-0.1.42.md)。
