# 0.1.37 密码库导航与编辑体验验证

本轮移除概览入口，管理页直接打开全部项目；重排新建与编辑表单，增加轻量动效，并支持与 Android 原生格式一致的 API 密钥。功能说明见[导航阶段更新说明](RELEASE-navigation-20260914.md)。本文件记录当时的本地开发验证，正式发布结果见 [0.1.37 发布验证](../VALIDATION-0.1.37.md)。

## 构建与自动化检查

- `npm test`：126 个文件、1,175 项测试通过。
- `npm run build`：TypeScript、223 个字体图标及生产构建通过；额外使用 `vue-tsc` 检查 Vue 模板类型，通过。
- MDBX2 Native Host：50 项测试通过，Clippy 在 `-D warnings` 下通过，0.1.1 Release 可执行文件构建成功。
- 供应链检查通过，生产 npm 依赖审计为 0 个漏洞。
- 实际工具栏 Popup 探针通过，覆盖 390×520、200% 字号、六种额外离线语言、搜索和复制回退。

## 浏览器回归记录

首次完整 Chromium 回归共 159 项，156 项通过、3 项失败。处理结果如下：

1. 锁定状态自动填充测试按新版表单先展开“更多选项”。
2. 修复弹窗入场结束时抢走已进入表单的焦点问题，新增快速输入和锁屏回归测试。
3. 大字号测试适配新的类型选择控件，排除关闭的折叠内容；编辑表单增加容器宽度判断，使 200% 字号下的字段及时转为单列。

最终构建随后运行 API 密钥、管理页、锁定自动填充、视觉、响应式和多语言等 45 项针对性回归：44 项通过，1 项遇到测试启动时序超时。该测试在导航尚未挂载时跳过了抽屉按钮，已改为等待按钮显示后打开导航；对应的 800px、200% 字号 MDBX2 WebDAV 加入窗口场景连续重跑 3 次全部通过。

当前测试集包含新增用例后共 160 个场景。以上为完整运行与后续针对性复测记录，不代表最终版本一次完整运行了 160 项。

## Android API 密钥互通

- 对照 Android 源码验证 `api-token` 原生对象、两种有效负载 schema，以及备注、自定义字段和收藏标签；保留对象 UUID、字段数字 ID 和未知字段。
- 使用真实临时 MDBX2 数据库验证对象与标签原子写入、移动、复制、删除和恢复。Android 仅修改标签、对象版本未变化时，插件仍能识别变更；与本地修改或删除并发时保留冲突。
- 旧版助手缺少 API 元数据能力时，写入和删除均在发送凭据前停止。
- 对最终 0.1.1 可执行文件执行隔离的 Native Messaging 握手，确认协议版本为 2，`supportsApiTokenMetadata` 为 `true`。临时应用数据目录未连接用户真实的助手存储。
- 本轮完成源码格式核对、真实临时数据库测试和插件测试，未执行 Android 真机或 instrumentation 验收。API 密钥支持本地库和 MDBX2；普通 WebDAV JSON、Bitwarden 和 KeePass 不提供原生 API 类型编辑映射。插件归档状态由 Android 保留，但 Android 当前不显示该状态。

## 视觉与性能检查

- 检查浅色、深色的全部项目、类型选择、密码编辑、API 编辑、银行卡、证件及 API 详情，共 14 个视图；无页面异常，Axe 检查未发现严重或关键级别问题。
- 浏览器回归覆盖 320px 和 800px、200% 字号下的表单布局、滚动与底部保存按钮。弹窗切换保持互斥，系统减少动态效果时关闭动画，锁屏立即移除敏感内容。
- 更新 8 张使用虚构记录生成的商店截图，12 项官方图标检查通过；包内 5 份 Monica PNG 与原始资源逐字节一致。
- 2,000 条模拟登录项和 100 条 OTP 的性能探针中，登录列表实际渲染 50 行；OTP 共用 1 个定时器，同一周期内观察 4 秒未发生重复签名计算。请求 GC 后，全部项目页保留的 V8 堆约 8.46 MiB，登录列表约 8.71 MiB。这不是浏览器总内存或独占机器上的性能基准。
