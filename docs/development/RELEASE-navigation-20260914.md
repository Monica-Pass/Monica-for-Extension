# 0.1.37 密码库导航与编辑体验

管理页现在直接打开“全部项目”。原概览页面已移除，密码源、分类、收藏、类型筛选以及归档和回收站继续可用；原有密码库和备份中的旧布局偏好保持兼容。

- 新建时按内容类型选择，编辑页面统一为基本信息、主要字段和补充信息。复杂配置按需展开，底部保存／取消保持可见。
- 新增独立 API 密钥类型：服务商、密钥、可选 API 地址、备注、收藏和自定义字段。密钥默认隐藏，不参与网站自动填充。
- SSO 收进密码记录的“登录方式”，与 Android 的第三方登录设置对应。
- 页面切换、弹窗和展开操作加入短时动效，系统启用减少动态效果时自动关闭；列表继续分页，不逐项播放动画。
- 界面语言移到“设置与备份”，保持八种语言及跨页面同步。

API 密钥可存入本地库或 MDBX2。与 Android 同步需同时安装本机助手 **0.1.1**；插件沿用 Android 的原生对象和标签，保留备注、自定义字段、收藏及未知字段。两端同时修改时保留冲突，普通 WebDAV JSON 备份、Bitwarden 和 KeePass 不提供此原生类型的编辑映射。插件的 API 归档标记由 Android 原样保留，Android 当前不显示该状态。

更新现有开发者模式安装时，在扩展管理页对原来的 Monica 点击“重新加载”。如果使用相同的加载目录，现有浏览器密码库继续保留。所有本地验证均使用临时浏览器配置和模拟记录，安装包只包含程序与资源。
