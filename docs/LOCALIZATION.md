# 本地化支持范围

Monica for Extension 从 0.1.26 起支持与 Android 版一致的 8 种语言：

| 语言 | 代码 | 选择器中的名称 |
| --- | --- | --- |
| 简体中文 | `zh-CN` | 简体中文 |
| 英文 | `en` | English |
| 日语 | `ja` | 日本語 |
| 韩语 | `ko` | 한국어 |
| 德语 | `de` | Deutsch |
| 西班牙语 | `es` | Español |
| 俄语 | `ru` | Русский |
| 越南语 | `vi` | Tiếng Việt |

管理页的语言选择位于“设置与备份”顶部的“界面语言”，侧栏专用于导航和锁定。登录页和 Popup 底部也可切换语言。默认选择“跟随浏览器”，按照浏览器语言偏好顺序选择首个支持的语种；例如 `de-AT` 使用德语、`es-MX` 使用西班牙语，没有匹配语种时使用英文。中文区域目前统一使用简体中文。手动选择后固定该语言，再选择“跟随浏览器”可恢复自动选择。默认外观仍跟随系统，也可在“设置与备份 → 外观”中固定为明亮或深色。

语言选择保存于 `chrome.storage.local` 的 `monica.locale`，并同步到管理页、Popup 和网页提示；`system` 表示跟随浏览器。旧版中英文偏好保持有效，扩展页面的同名 localStorage 偏好在首次启动时迁移。内容脚本不会读取网站 localStorage 中的语言偏好。较慢的旧加载请求不能覆盖新选择；语言包加载失败时保留可用界面并允许重试。

## 覆盖范围

- 管理页、编辑器、密码源与恢复对话框、生成器、Popup。
- 密码保存/更新和 Passkey 确认提示；打开的提示切换语言时保留已选账号、保存位置和处理方式。
- 内置状态、验证与错误文案，以及随当前界面语言格式化的日期和数字。
- Chrome `_locales` 中全部八种语言的扩展名称、说明与工具栏标题；不支持的浏览器语言回退英文。

用户录入的名称、账号、笔记、密码、来源文件及第三方服务返回的原始内容保持原样，不通过翻译器。帮助文档以中文或英文分别维护，并非每篇文档都有两种语言版本。字段识别规则与 UI 语言独立，不根据语言设置放宽网站、frame 或表单字段匹配。

每套非中文词库覆盖 2858 条应用文案，并保留原文中的全部变量。新增六种语言复用了 Android 已翻译文案，其余初稿由离线翻译辅助生成，导航、认证、免解锁授权和 Passkey 确认等关键文案已逐项校订，残留英文标签已检查。这六种语言尚未经过各语种母语使用者的完整审校。

## 维护和验证

`src/i18n/locales.ts` 定义语言列表，`src/i18n/runtime.ts` 提供 Vue 页面和内容脚本共享的语言状态与翻译函数，`src/i18n/index.ts` 提供 Vue 响应式包装。中文原文作为内置文案键，英文放在 `src/i18n/ui-en.json`；其他语言在 `public/locales/ui-<语言>.json` 中，按需加载并缓存。扩展运行时只读取已打包资源，不向在线翻译服务发送文本。Manifest 仅开放明确列出的六个静态语言文件供网页提示使用，不开放密码库资源或额外脚本。动态数据通过参数传入，禁止翻译用户内容来寻找文案键。

从 0.1.27 起，每个运行上下文只常驻英文回退词库和至多两套其他词库；切回已释放的语言时从本地资源重新加载。网页内容脚本在首次保存提示或 Passkey 流程需要时才初始化语言，普通网页不会仅因安装扩展而额外加载所选语言包。分页、页码与结果范围均支持八种语言，并经过 320×480 / 200% 字号布局验证。

新增语言时需补齐词库和 Manifest 文案，再运行以下验证：

1. `src/i18n/runtime.test.ts`：全部词库覆盖、变量占位符、浏览器语言优先级、偏好迁移、跨页面同步、加载竞态、失败重试与词库释放后重新加载。
2. `src/content/prompt-localization.test.ts`：切换到每种非中文语言时，不重置保存策略或 Passkey 选择。
3. `tests/e2e/localization.spec.ts`：真实扩展中的语言切换、用户数据保留、系统主题、英文各页面在 375px / 200% 字体下的布局。
4. `tests/e2e/multilingual.spec.ts`：新增六种语言在离线状态下创建密码库、检查全部功能页、窄屏和 200% 字号、实际编辑保存、免解锁填写及跨页面切换。
5. `tests/e2e/responsive-layout.spec.ts` 与 `accessibility.spec.ts`：多尺寸布局、对话框、键盘焦点与自动化无障碍检查。
6. `tests/e2e/performance.spec.ts`：八语言分页控件、全库搜索和翻页填写，以及普通网页不额外加载词库。
7. `tests/e2e/vault-home.spec.ts`：模块标题、数据库切换、布局编辑、卡片选择、空状态与分页在八语言、深浅主题、320px / 200% 字号下可用。
8. `tests/e2e/home-usability.spec.ts`：首页密度、默认数据库、卡片草稿与失败重试、快捷复制、折叠记忆和同步处理入口；原生对话框的背景隔离、键盘焦点恢复、320×568 / 200% 字号下的内容滚动与保存操作经过检查。

独立第三方无障碍审计、所有屏幕阅读器与所有网站的兼容性不由这些自动化测试保证。
