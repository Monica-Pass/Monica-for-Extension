# 0.1.41 密码库界面整理

> 本地开发阶段记录：文中的版本号未作为 GitHub Release 发布，相关改动已汇总到[正式版 0.1.37](RELEASE-0.1.37.md)。

参考 m3e-canvas 调整密码库、新建类型、详情和编辑界面，保留 Monica 的 Nothing 风格与官方应用图标。

- 密码库使用连续列表，名称、摘要、来源和操作对齐。数据库切换、收藏与当前筛选范围直接可见。
- 详情恢复宽屏双栏，修复被编辑器样式挤窄的问题；正文滚动时标题与操作仍可见。
- 新建类型按两组连续列表展示；编辑器先填名称，再填写账号或类型专用信息，补充字段独立分组。
- 支持窄窗口、放大字体、键盘操作和减少动态效果，沿用离线字体与明暗主题。

没有新增运行时依赖或修改密码库格式。Android 兼容、自动同步和 Passkey 策略沿用 0.1.40。

附带可用 m3e-canvas 打开的 [布局稿](design/monica-vault.m3e.json)，全部示例为虚构数据。参考方式见 [设计说明](UI_M3E_CANVAS.md)，检查结果见 [验证记录](VALIDATION-0.1.41.md)。
