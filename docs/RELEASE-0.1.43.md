# 0.1.43 M3E 表单与交互

> 本地开发阶段记录：文中的版本号未作为 GitHub Release 发布，相关改动已汇总到[正式版 0.1.37](RELEASE-0.1.37.md)。

输入框、下拉框、复选框、单选项、开关、滑块、展开区域和主要弹窗改用真实的 M3E Web Components。删除旧样式造成的重复描边，Nothing 继续仅提供可选配色。

- 新建、编辑和设置表单统一为 filled 输入，保留原有字段、校验、加密保存和数据格式。
- 项目、密码源、文件夹与历史记录采用多行列表组件；图标、标题和说明分别布局，长文字可以换行。紧凑登录列表省略过长摘要，详情保留完整值。
- 拆分菜单和下拉框支持键盘操作；Escape 关闭当前下拉时保留编辑草稿；关闭弹窗后恢复触发位置的焦点。
- 调整 200% 文字、窄窗口和短窗口下的弹窗空间，使保存操作保持可达。语言切换会更新下拉菜单中的选项文字。
- 设置开关只有在保存成功后切换；保存失败显示错误并允许重试。
- 收起补充字段或取消验证码绑定时保留编辑草稿，避免子控件的关闭事件误取消整个编辑窗口。

锁定 `@m3e/web` 为已验证的 2.6.1。它是 M3E 项目的组件库，并非 Google 官方 Material Web。无 Popover API 的浏览器保留表单选择器与新建菜单的兼容回退。

本次为 UI 迁移，没有改变 Android 数据格式、加密、WebDAV / Bitwarden 同步协议或 Passkey 策略。复杂来源管理与附件流程保留既有弹窗容器及确认逻辑。

参见[设计与组件说明](UI_M3E_CANVAS.md)及[验证记录](VALIDATION-0.1.43.md)。本地包仅包含程序资源，不包含密码库、浏览器配置或测试工件。
