# 浏览器扩展逐记录加密存储验证

未发布开发版；沿用 1.0.104 的版本标识。仅扩展自身的 IndexedDB 主库变更，KDBX、MDBX 和 Bitwarden 服务器的数据格式不变。

## 本机 Edge 对照

使用隔离配置的真实 Edge、IndexedDB、WebCrypto 和生产 SecureVaultService。同一构建对照兼容的整库写入路径与逐记录路径，不是两个发行版之间的比较。每种情况三次，表为中位数。编辑计时不含初始化、首次迁移和冷解锁；每组结束后重新解锁核对数据。Bitwarden 使用真实 provider 和同步协调器，服务器响应在进程内合成；完整同步之后三次分别只下载一个 Cipher。没有使用真实账号。

| 操作 | 整库写入 | 逐记录写入 | 提交的数据量（整库 → 逐记录） |
| --- | ---: | ---: | ---: |
| 1,000 条中编辑一条登录 | 40.7 ms | 5.2 ms | 1,081,750 → 4,957 B |
| 5,000 条中编辑一条登录 | 149.9 ms | 8.0 ms | 5,423,086 → 8,236 B |
| 5,000 条 Bitwarden 登录中更新一个 Cipher | 645.3 ms | 232.1 ms | 8,349,922 → 17,046 B |

数据量统计传给 vault 对象仓库的 put/add 值：二进制密文和 IV 按字节计，其余按 JSON 的 UTF-8 大小计。不含键、删除操作、数据库引擎日志或实际磁盘放大。旧路径会同时传递完整恢复副本数组。CPU、内存占用、真实服务器延迟不在此结论内。

在补齐旧 PBKDF2 迁移用例后又跑了一轮。同样取三次中位数，1,000 条本地编辑为 31.1 → 3.4 ms，5,000 条为 91.9 → 4.4 ms，5,000 条 Bitwarden 单条更新为 354.6 → 213.5 ms。两轮写入字节数一致，时延受本机负载影响。

## 验证范围

- 从实际创建的 IndexedDB v1 载入合成旧信封，模拟暂存成功后切换失败：旧格式仍可读取，原字节不变。重新解锁后激活 v2，并验证保留的原信封、附件和未知字段。
- 对使用 PBKDF2 的合成旧库，注入切换失败后确认旧信封原字节可读。重试后直接用 Argon2id 激活已读回验证的记录，新会话使用原密码解锁，恢复列表不含旧密钥副本。
- 在 IndexedDB 主记录写入时注入事务中止，确认主记录未变，冷重开仍是旧值。正常编辑后冷重开可读新值；改主密码后旧密码拒绝，当前恢复列表不含旧密钥的副本。
- 删除必需记录后认证失败，不自动回退至旧库；独立 v1 加密备份在新库恢复成功。按旧数据库版本打开已升级的库会遭浏览器拒绝。库锁定后解锁、丢失提交回复及实际 Edge 重启，另由本地传输回归覆盖。
- 格式测试检查调换记录与旧密文替换、缺失记录、重复值与顺序、未知字段以及大记录分块的缺失和重排。所有合成测试资料只留隔离配置。
- 本次未发布、未操作用户密码库。无法防止整个浏览器配置连同库头一起回滚。冷解锁仍验证整个库；首次迁移需要暂时容纳两份数据。定期全量恢复点、导出、修改保护方式不属于日常单条写入样本。

安全套件 760 项通过。打包后 Edge 导出与恢复页的首轮 1/2，更换保护方式后立即出现新密钥的副本。修正创建时机后原断言 2/2 通过。全套单元测试首轮 4,709/4,710，唯一失败是新增文档后索引计数少一篇。更新索引并在最终源码上复跑安全目录和索引，724/724 通过。Chromium 与 Firefox 构建通过，最终 Firefox 扩展与 UI 验收、运行时安全审计通过。

## 后续同步优化

本机 Edge 使用冻结的优化前后代码，按前、后、后、前运行。两边均已启用逐记录存储。下表是各场景的样本中位数。

| 场景 | 优化前 | 优化后 | 耗时减少 | 每版样本数 |
| --- | ---: | ---: | ---: | ---: |
| 5,000 条 Bitwarden 登录中同步一个变更的 Cipher | 195.50 ms | 145.00 ms | 25.8% | 6 |
| 2,000 条已打开 KDBX 条目的普通同步，无待写修改 | 197.65 ms | 167.95 ms | 15.0% | 10 |

Bitwarden 使用真实 IndexedDB，远端响应由本机合成。对应样本提交的数据量两版相同，为 17,006、17,046 和 17,084 字节。KeePass 计时覆盖打开后的 provider 同步，另验证单条编辑、导出及重开。冷解锁、导出和整文件远程写入的耗时无法从这组样本得出。原始样本和运行日志保留在本机任务目录 `.codex-tasks/20261118-provider-cost/`。

同步相关回归 2,126 项通过，包含 Bitwarden 在远端写入期间收到新编辑的场景。新增负向测试验证调用方修改快照不会修改缓存或待同步队列，锁定后也不能重新读取快照。最终安全套件 761 项、类型检查、构建、运行时安全审计和 lint 均通过。Bitwarden 模拟服务器互通 2 项和真实 Edge 扩展的 Bitwarden 文件夹及 KeePass 分组流程 2 项通过。

KeePass 互通的 Android 应用构建路径最初未找到 Kotlin 测试。修正 AGP 源集后生成夹具成功，回读阶段因共享构建的 `R.jar` 被占用中止。独立 JVM 的早期运行先后遇到 SDK 路径缺失、Kotlin 序列化编译插件不匹配及旧 Kotpass 接口缺失。最终使用当前 Android 内置 Kotpass 与 KDF 桥接源码，在 JVM 回退路径完成 1 项双向互通。覆盖 AES-256、ChaCha20、保护位、未知字段、自定义图标、附件、历史、字段引用和 Passkey。测试使用合成 KDBX 和 Android 核心代码，应用构建路径的回读仍未完成。
