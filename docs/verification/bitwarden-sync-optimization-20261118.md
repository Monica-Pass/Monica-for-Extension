# Bitwarden 同步与 Base64 性能优化验证（2026-11-18）

版本保持 1.0.104，内部代号 Sengoku Nadeko。本轮继续既有性能评估和 `dist` 暂存构建改动；未修改 Android、用户库、原生格式或 KDF，未提交、推送或发布。

## 实现与边界

- 正常 `check-remote` 先在原授权读取门内检查账号绑定、会话、库代号及待写/回执/冲突/整批传输/项目移除记录。清洁状态仅遍历缓存条目，无整库复制；网络后重新核验认证信封与库代号，并再次检查取消。无变化只返回 `unchanged` 标记，空 `items` 不进入入库流程。
- revision 变化时复用预取的完整响应，按原持久流程入库；冷缓存、15 分钟超时、令牌轮换和本地变化保留原路径。缺少 Steam secret 的投影不进入快路径。存在该来源的项目移除历史时也保守回退，未缩减恢复保护。
- 自动调度只读取账号/队列路由投影，不为调度复制条目；账号配置仍是隔离副本，原认证和不续期规则保留。
- 操作内复用不可导出 AES/HMAC CryptoKey；AES 用途仍分开、MAC 仍先校验。复用仅针对显式准备的 key 对象，以弱引用关联；原字节改变或清零会使缓存失效，不把导入密钥放进远端缓存或持久化。
- 使用原生 typed-array Base64；不支持时保留旧实现。原生解码拒绝时交给 `atob`，保留原错误行为。空值、二进制、subarray、块边界、空白、缺 padding 和非法输入均覆盖。
- 新回归发现提供方先准备远端缓存、本地入库随后失败会使下一次误报无变化。协调器失败时现撤销该账号缓存，重试重新读取，不提前确认未入库的 revision。

## 同条件生产链路对比

冻结优化前后 esbuild bundle，使用 Node 22.14.0 执行实际 provider/coordinator/vault/WebCrypto。100、1,000、5,000 条合成登录，三个执行轮次，每轮无变化和单 Cipher 增量各三次。每次计时结束后核对完整条目数量，不把核对读取计入时间或计数。HTTP 为进程内合成响应，存储为 MemoryVaultStorage；不含真实网络、IndexedDB、登录 KDF。主机负载不是实验室固定条件，计数比小幅耗时波动更可靠。

下表为 5,000 条中位数，冷全量/本地编辑各 3 样本，无变化/单 Cipher 各 9 样本：

| 操作 | 优化前 | 优化后 | 结构证据 |
| --- | ---: | ---: | --- |
| 冷 Bitwarden 全同步 | 2,433ms | 1,847ms | 密钥导入 40,002 → 4；实际解密次数保留 20,001 |
| 远端无变化检查 | 98.8ms | 13.2ms | 数组条目复制 10,000 → 0；完整状态条目复制 5,000 → 0；两版均零写入 |

## 真实 Edge

使用已安装 Edge 157 与自有隔离配置，未启动 Chrome。生产 `encoding.ts` 在 Edge 执行 10,024 组原生/旧版对照，无接受范围、错误类型或字节差异。单次 10MiB 二进制往返：编码 207.5 → 5.0ms，解码 88.0 → 12.4ms；逐字节核对正确，编码长度均为 13,981,016。它是转换微基准，不是整库保存或云同步测速。

13 项 Edge E2E 一批通过（约 1.6 分钟）：5 项管理页记录/密码轮换/完整备份恢复及取消，6 项弹窗渐进加载/搜索/分页/锁定，1 项 Base64 对照，以及 1 项真实扩展 Bitwarden maFile 403 下载失败后重试恢复。全部为合成数据，测试配置清理 13 份。

## 剩余瓶颈及跨端边界

未实现逐记录加密持久化。扩展主库仍为 version-1 完整 JSON/AES-GCM 信封；单条变化、独立诊断仍可能全库编码/加密/写入，需单独设计迁移、恢复和事务后再改。未通过保留可变入库 state 缓存、降低 KDF 或跳过回执换取速度。

Android 只读对照沿用 [前阶段评估](extension-performance-20261118.md)：常规 Bitwarden `/sync` 全量网络读取、本地主要按 Room 记录事务保存；没有同条件 Android/扩展速度比较。KDBX 使用原生对象与加密工作副本，远端保存完整文件，本地原文件需导出；MDBX2 浏览器通过 Rust/WASM 原生事务与 MEMFS/IndexedDB 64KiB 变化块持久化，不自动覆盖桌面原文件。此轮未修改或专项计时 KDBX/MDBX、测试原生助手、真实云、Firefox、最低版本浏览器或低性能设备。
