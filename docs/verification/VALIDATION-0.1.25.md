# 0.1.25 多尺寸适配与验证记录

日期：2026-09-11。本地开发包，发布证据如实记录尚未提交的工作树状态。

## 界面与操作

- 保留 Nothing 黑白外观、离线字体、简体中文与英文。默认跟随系统，也可手动切换浅色和深色。
- 管理页覆盖 320–2560px 窗口。窄屏工具栏将搜索与操作分行，平板概览使用两列，宽屏使用四列并限制内容宽度。
- 操作按钮至少 44px；图标按钮保持稳定尺寸。放大文字时，长标签按内容换行，按钮的隐形点击区域不会覆盖相邻操作。
- 窄屏侧栏有关闭按钮、背景关闭、Escape、焦点循环和焦点返回。短横屏可滚动到所有分类、语言和锁定操作；锁定后再次解锁会回到主内容。
- 登录项与钱包、笔记、验证码编辑器保留底部保存和取消区域，字段独立滚动。详情页按可用宽度排列标签、值和复制按钮。
- Popup 适应较短的屏幕工作区，解锁标题和说明使用完整表单宽度。存在可免解锁填写的匹配账号时，主密码输入框不再自动抢占焦点。

## 验证范围

新增 16 项 Chromium 回归，包括 10 组窗口/字体组合、窄屏导航完整焦点流程、4 组短窗口编辑保存流程，以及短 Popup 的锁定填写与解锁。

窗口组合：320×568、360×640、390×844、768×600、1024×600、1366×768、1920×1080、2560×1440；另外检查 320×480 与 800×360 的 200% 字体。编辑器补充检查 560×320 横屏与 768×600 大字号。

尺寸检查使用含合成记录的页面，并实际打开登录、钱包、笔记、验证码与 Passkey 详情。除页面边界外，还验证按钮尺寸、标签裁切、Shadow DOM 点击区域、保存按钮可见性及真实表单提交。Popup 额外检查 390×600 / 100% 与 320×360 / 200% 下的解锁说明宽度，防止文字被挤入图标列。测试均使用隔离浏览器配置。

## 兼容性

本轮调整界面布局、按钮呈现和焦点交互，未修改密码库、Android 记录、Passkey 密钥或同步协议。此前的 Android KeePass、MDBX2 与 Native Host 互通验证见 [0.1.24 记录](VALIDATION-0.1.24.md)；本轮未重复运行 Android 和 Native Host 测试。

普通登录项的免解锁填写仍需用户逐项标记，并执行网站、字段和文档匹配检查。验证码、Passkey、查看或编辑密码库仍需要解锁。只有 Android 设备密钥别名的 Passkey 继续保留为元数据，真实 Windows Hello 硬件验收仍受当前环境不可用的限制。

## 安装与升级

新版 ZIP：`release/monica-extension-0.1.25.zip`。可加载目录：`release/monica-extension-unpacked`；开发构建位于 `dist`。

已安装的扩展请继续使用原加载目录，更新后在 Chrome/Edge 扩展管理页点击“重新加载”。首次安装可开启开发者模式并选择“加载已解压的扩展程序”。更换绝对目录可能改变开发者模式扩展 ID，原有本地数据不会自动迁移。

Windows 连接组件继续使用 `release/monica-mdbx2-host-windows-x64-0.1.0.zip`，安装说明见 [0.1.24 记录](VALIDATION-0.1.24.md#安装和升级)。未改动日常浏览器配置或 Android 项目。

预览图在 `store-assets/` 和 `.artifacts/nothing-preview/`，均为合成账号。
