# 0.1.40 自动与增量同步

> 本地开发阶段记录：文中的版本号未作为 GitHub Release 发布，相关改动已汇总到[正式版 0.1.37](RELEASE-0.1.37.md)。

手机上传修改后，插件可自动接收并刷新列表、详情和 Popup；浏览器保存也会自动安排上传。“设置与备份”新增默认开启的自动同步开关。

- Bitwarden 采用官方 SignalR 通知协议，普通条目变化通过单 Cipher API 下载和解密。断线、worker 重启、令牌过期和漏通知会自动恢复或校对。
- WebDAV 在页面可见时每 15 秒检查、后台约每分钟检查。MDBX2 沿用 Rust 增量分段；KDBX 与 Android 快照未变化时不下载。文件格式各自的完整传输限制保留。
- 自动刷新保留正在编辑的草稿；保存前检测远端或其他窗口修改。同步不会延长无操作锁定时间，锁库和关闭开关会停止后台任务。
- 单源失败隔离、失败退避、限流等待、分批上传和持久回执保护继续生效。历史正计数 Passkey 会等待正在进行的同步，零计数离线使用保持不变；包含独立审查后的计数高水位保护。

跨端前提与实现边界见 [同步兼容说明](SYNC_COMPATIBILITY.md)，测试与产品包见 [验证记录](VALIDATION-0.1.40.md)。
